# NflPredictionThing
Its an NFL prediction tool based on ESPN's football power index numbers

It uses unsupervised machine learning algorithm called K mean clustring with ESPN's football power index but only has 10 random games selected from the 2025 season so its kind of very inaccurate right now. Can be made better with more data points from more games which I might do in the future.

you basically enter the 2026 NFL power index from both offense and defense of the home and away team and it uses the 10 games to predict who it thinks will win.

Link to ESPN power index page: https://www.espn.com/nfl/fpi
